# Página Código Judaico

Página estática em francês com o título **RICHESSE ET STABILITÉ GRÂCE À CES 5 PRINCIPES JUIFS**, vídeo VTurb e fundo `#23454d`.

O aviso abaixo do vídeo mostra automaticamente a data de amanhã em francês, com base no horário local do visitante, e se atualiza enquanto a página estiver aberta.

## Como usar

Abra `index.html` no navegador ou publique o arquivo em uma hospedagem estática. Não é necessário instalar dependências ou executar uma compilação. O vídeo requer conexão com a internet para carregar o player externo.
